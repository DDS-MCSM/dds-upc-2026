# releases/

Aquesta carpeta no conté el paquet. El tarball `mitre_1.0.0.9100.tar.gz` i el seu `SHA256SUMS` es publiquen com a *release* de GitHub a <https://github.com/DDS-MCSM/dds-upc-2026/releases>, no dins del repositori.

Per instal·lar des del tarball: descarrega'l de la *release*, comprova'n el SHA-256 amb `SHA256SUMS` i segueix la guia d'instal·lació de [`01-S1`](../01-S1/).
