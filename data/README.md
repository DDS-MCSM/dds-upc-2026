# data/

Aquesta carpeta no conté dades. **Cap inventari de programari personal ni cap dataset es puja a aquest repositori**: els inventaris són del teu portàtil i no en surten.

Les dades de l'assignatura (CVE, CPE, CWE, CAPEC, ATT&CK) arriben amb el paquet `mitre` de la branca `dds-2026`; no cal descarregar res més. Si generes fitxers locals (per exemple un inventari en JSON), queden fora del control de versions: el `.gitignore` ignora `*.json` i `outputs/`.
